# React_Backup

A collection of small React + Vite practice projects.

## Projects

- **curd/** — Tailwind-based CURD UI form (create post)
- **backup_1/** — React + Vite (Cards / Follow UI)
- **backup_2/** — Counter App (React + Vite + Tailwind)
- **backup_3/** — Profile Cards (React + Vite + Tailwind)

## How to run a project

From this folder, `cd` into the project you want and run:

```bash
npm install
npm run dev
```

## Notes

Each subfolder is an independent Vite project (has its own `package.json`).
